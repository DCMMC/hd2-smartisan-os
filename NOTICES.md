# Attribution and source provenance

This repository contains an unofficial HTC HD2 adaptation of Smartisan OS. Smartisan, CyanogenMod, HTC, Qualcomm and upstream authors retain their respective rights. Original notices in ROM components continue to apply; no blanket relicensing of third-party firmware or code is intended.

`sources.lock.json` records the pinned HD2 base, Smartisan donor, kernel/device sources and toolchain. Proprietary system binaries are distributed only in the ROM release archive. The public repository contains the Smartisan-specific patch scripts, manifests and sanitized device evidence needed to review this adaptation. The kernel is inherited from NexusHD2 V4.0 and was not rebuilt for this release.
